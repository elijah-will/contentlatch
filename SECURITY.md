# Security Policy

## Supported Versions

The latest stable release of ContentLatch receives security fixes. Older releases are not actively maintained.

Latest stable release: [WordPress.org](https://wordpress.org/plugins/contentlatch/)

## Reporting a Vulnerability

Please report security vulnerabilities through [GitHub private vulnerability reporting](https://github.com/elijah-will/contentlatch/security/advisories/new) on the ContentLatch repository.

Do **not** disclose security vulnerabilities through public GitHub Issues or Discussions.

When reporting, include:

- Steps to reproduce the issue
- Affected ContentLatch version(s)
- Potential impact
- Relevant technical details (for example, request payloads, stack traces, or environment notes)

## Disclosure

Reports are reviewed and investigated. Please allow time for assessment and, when needed, for a fix to be prepared.

We request coordinated disclosure: keep the vulnerability private until a fix is available and released.
