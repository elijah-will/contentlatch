Content quality-control rules for Advanced Custom Fields (ACF) backed WordPress content.

== Description ==

ContentGuard lets you define content rules against ACF fields and then:

* Validate content when editors save or publish.
* Audit existing content against those rules.
* See which content passed, has warnings, or failed.

Requires Advanced Custom Fields 6.0 or higher (Free or Pro). Pro is not required for V1.

== Installation ==

1. Install and activate Advanced Custom Fields 6.0 or higher.
2. Upload the plugin files to `/wp-content/plugins/contentguard`, or install through the WordPress plugins screen.
3. Activate ContentGuard through the 'Plugins' screen.
